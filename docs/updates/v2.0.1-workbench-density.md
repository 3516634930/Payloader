# v2.0.1 批次 M：CTF 工作台交互密度对齐随波逐流

> 日期：2026-09-22。范围：展示层与状态管理 + 7 个新字表映射操作；引擎既有实现不动、受众分流不动、零联网不动。

## 需求回顾（用户口径）

随波逐流对比结论：当前工作台"选分类 → 下拉选操作 → 点执行"三步太重，无全局密钥栏，输出区无搜索/导航，长输出找 flag 靠肉眼滚。目标：粘贴 → 点动作按钮串链 → 输出区正则搜 flag 直接命中；密钥只填一次。

## 调研结论（关键事实）

- 工作台组件为共享单件：`CodecWorkbench.tsx` 同时服务渗透视图（`EncodingTools`）与 CTF 密码域（`CipherWorkspace`），增强自动惠及两视图；"杂项/流量域的文本工作区" = `CtfHero.tsx`（全域置顶共享）。
- `verify-encoding-tools.mjs` 在 vm 中直载引擎源码，新操作必须补用例（verify:codec 门禁）；`frontend-contract.test.mjs` 对 CodecWorkbench 680px 移动样式做正则断言，改造须保结构。
- 码表调研（子代理完成，含来源交叉验证）：
  - **云影密码**：0 分隔、1/2/4/8 段内求和 → A1Z26；向量 `8842101220480224404014224202480122` → `WELLDONE`（攻防世界真题，多源一致 + 自行验算）。
  - **Pizzini**：序号+3 拼接（A=4…Z=29），贪心自分隔解码（1/2 开头取 2 位否则 1 位），兼容 1–3→X/Y/Z（CacheSleuth JS 源码逐字核实；XCTF 语境下历史向量有转写失真，以实装规则为准）。
  - **Decabit**：dcode.fr 全 127 行 10 脉冲表（5+/5-，126=全+），ASCII 映射；dcode+kryptografie.de 双源一致。
  - **Cetacean**：**CyberChef 官方密码**（非"鲸目图片表"，调研确认后者不存在公开标准）：字符 UTF-16 码元 16bit，1→e、0→E，空格原样；KC7 实战变体 A/B 归一化兼容。源码+官方测试双确认。
  - **Albam**：默认 A↔N 半表互换（+13 对合，catencode/fidonode/GC Wizard 多源；贴合希伯来 Temurah 原意），备选 CacheSleuth +11（variant 参数切换）。
  - **Carbonaro**：CacheSleuth 对合查表（8 个不动点 H/J/K/Q/U/W/X/Y），向量 `THE↔DHI`；单来源，无第二实现可对照（交付说明标注）。
  - dcode 全站扫描：仅 Decabit 存在；Pizzini/Cetacean/Albam/Carbonaro 用各自最权威实装源。
