## 演进主线

1. **实战能力**（v2.0.1）：CTF 解题能力 + GitHub 内容源监控，先服务自己和核心用户。
2. **内容能力**（v2.0.2 - v2.0.5）：EXP 类型与源码 → 统一版本历史 → 正式发布流程。
3. **社区生态**（v2.0.6 - v2.0.11）：账号权限 → 注册投稿 → 人工/AI 审核 → 复现统计。
4. **分发与双仓协同**（v2.0.12 - v2.0.15）：同步数据桥 → 升级路径 → MCP 与 AI Skill 分发。
5. **收口**（v2.0.16）：全面验收，成为集成平台稳定版。
