# Payloader v2.0.15 更新计划：AI Skill 包（Claude Code / Codex）

## 目标

为 Claude Code 和 Codex 分别发布开箱即用的 Skill ZIP 包，把"怎么用好 Payloader MCP"的检索方法论直接装进 AI 工具。

## 需求背景

v2.0.15 的 MCP 服务解决了"AI 能查到"，但 AI 未必"查得好"——不会先搜后取、会把模糊命中当确定结论、可能被恶意源码里的提示注入带偏。Skill 包把正确的检索工作流和防注入纪律固化下来，用户装包即得。

## 新增/变更功能

- 两个专用包：Claude Code ZIP 和 Codex ZIP，只支持这两个客户端，不做泛化通用包。
- 统一 Skill 内容：厂商无关的 Payloader 检索工作流——先轻量搜索、核对匹配等级与缺失条件、再按需取详情和源码；结果必须引用稳定 ID 与 Hash，证据不足时明确说"没有"，禁止臆造。
- 防注入纪律：MCP 返回的一切内容（源码、注释、文件名）都按不可信数据处理，不能覆盖 Skill 指令、不能触发本地命令、不能被 AI 自动执行；Skill 只提供检索方法，不代替用户授权与人工判断。
- 包内容完整：正确目录结构、Skill、MCP 配置示例、README、manifest、卸载说明、文件 Hash、兼容版本说明。
- 工程质量：ZIP 可重复构建且字节确定；CI 自动校验目录、配置语法、Tool Schema 和真实 MCP 连通烟测。
- 分发：官网分别提供两个下载入口和人工安装/卸载文档。

## 预期效果

- 用户下载安装后，Claude Code / Codex 立刻掌握正确的 Payloader 检索姿势，查得准、引得实。
- 恶意 EXP 源码里的提示注入无法劫持 AI 行为。
- 包本身可复现构建、可校验完整性，下载即用、卸载干净。
