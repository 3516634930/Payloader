# Payloader v2.0.16 更新计划：集成平台稳定版收口

## 目标

作为 v2.0.x 系列的收官版本：统一全部界面、冻结长期契约、清理所有临时机制，通过全维度验收，成为正式的"集成平台稳定版"。

## 需求背景

v2.0.1 到 v2.0.16 连续做了 16 个版本，期间积累了一些临时兼容层、双路径开关和过渡页面；五大对外契约（公开 API、同步 Manifest、MCP Schema、Skills Manifest、离线迁移包）也已经稳定运行。是时候做一次全面收口：对外承诺长期稳定，对内清掉技术债。

## 新增/变更功能

本版不新增任何新能力，专注统一与收口：

- 界面统一：公开站、用户后台、管理后台、审核工作区统一组件与交互，移除临时兼容页面。
- 契约冻结：正式冻结五大长期外部契约及其版本演进/弃用规则，对外做出兼容承诺。
- 清理：移除全部到期功能开关、迁移脚手架和旧别名；AI 集成等已验证能力转为常态。
- 完整性矩阵：内容、投稿、审核、发布、同步、MCP、Skills、客户端四平台等全链路端到端验证。
- 工程收尾：安全审计、依赖/SBOM/许可证检查、秘密扫描、性能容量、备份恢复与灾难恢复演练、升级/回滚演练、各类部署形态文档完善。
- 升级路径：明确旧版本（v2.0.0 / v2.0.1）到本版的唯一升级路线，软件清单、签名与资产 Hash 不可覆盖。

## 预期效果

- 五大契约对外承诺长期兼容，第三方集成可以放心依赖。
- 代码里没有遗留的功能开关和双路径，界面没有过渡页——系统回归简洁。
- 全链路（从投稿到 AI 分发）有端到端验证矩阵背书，安全、性能、恢复全部有演练证据。
- 成为真正意义上的"稳定版"：后续只做增量演进，不再有伤筋动骨的变更。
