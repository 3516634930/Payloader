# Payloader v2.0.8 更新计划：用户后台与统一投稿

## 目标

上线用户后台（`/user/`），投稿者可以为 Payload、工具、EXP 三类内容提交新增或修改投稿，并以公开昵称署名。

## 需求背景

用户体系（v2.0.7）和注册（v2.0.8）就绪后，社区贡献的入口该打开了。投稿机制要同时满足三点：贡献者得到署名荣誉、管理员拿到可直接审核的规范候选、平台不被恶意投稿拖垮。

## 新增/变更功能

- 独立用户后台：与公开站、管理后台分开构建；首次投稿前必须设置公开昵称，邮箱永不作为署名。
- 三类内容统一投稿：草稿、新增投稿、基于当前激活版本的修改投稿；提交即形成完整候选与服务端 Diff。
- 投稿备注：新增投稿可选，修改投稿必填说明改动原因；备注与 Diff 仅审核侧可见，不变成公开评论。
- EXP 投稿复用 v2.0.4 的整套安全上传与源码树机制，不另起炉灶。
- 权限模型：管理员显式授予投稿资格；审核员投稿与普通用户同流程，任何人都不能投稿后立即公开。
- 投稿管理：用户可查看状态和最终意见，可删除自己的草稿/被退回稿；已提交后的内容不可撤回、不可删除。
- 管理后台投稿统计：按用户看投稿量、类型分布、待处理数等，仅供观察与禁用判断，不做自动配额。

## 预期效果

- 社区用户有了正式的贡献通道，贡献记录沉淀为公开署名（昵称），形成正向激励。
- 管理员收到的每份投稿都是带 Diff、带说明的规范候选，审核成本可控。
- 恶意或低质投稿有观察数据支撑处置，且不影响公开站任何内容。
