# v2.0.1 追加批次提示词：随波逐流式菜单栏重构 + 操作大扩充（批次 M3/M4）

> 前置：批次 J/K/L/M2 已完成验收（门禁全绿：verify:codec 125 / test 210 / typecheck / lint）。
> 依据：用户实机截图对照（随波逐流 V7.4 全菜单）+ 用户明确反馈。
> 两条批次相互独立，可并行，也可与 v2.0.2 批次 N/O/P 并行。

## 批次 M3：顶部菜单栏重构 + flag 标红

**问题**：用户对照随波逐流实机界面提出三条 UI 否定意见：①操作入口在页面下方，应像随波逐流一样放顶部菜单栏；②操作平铺成按钮网格不对——该用下拉框；③输出里 flag/Flag/FLAG/ctf 等字样没有标红，扫一眼找不到。

**需求**：CTF 工具箱的操作导航重构为"顶部菜单栏 + 下拉菜单"，点击菜单项立即对当前输入执行；输出区自动标红 flag 类字样。

**方向**：
- **顶部菜单栏**（参照随波逐流：Base/Rot | 字符1 | 字符2 | 字符3 | 字符4 | 编码转换 | 带key解密 | 多key解密 | 进制转换 | 其他工具）：CTF 工具箱视图顶部（智能识别区上方或紧邻）放一条菜单栏，每个菜单点开是下拉操作列表，菜单项点击即执行对应操作并显示在输入区上方当前激活操作名。菜单分组命名与排序参照随波逐流（可在语义上合并同类，但必须顶部+下拉+点击即执行，不再平铺按钮网格）。
- 现有侧栏分类与按钮网格移除或折叠为辅助（若保留二次分组视图，也必须是下拉/折叠形态，不是平铺）。域切换（密码编码/杂项取证/流量分析）保留在工具箱标题行，菜单栏内容随域联动：文件/图片类菜单只在杂项域展示，流量菜单只在流量域展示。
- 菜单项带标记区分【解密】与加密（参照随波逐流【xx解密】方括号标记法），支持键盘方向键+Enter 选择。
- **flag 标红**：所有输出区（智能识别结果、工作台输出、文件探测报告）对 flag/Flag/FLAG/ctf/CTF/KEY/key 等关键词及 flag{...}/ctf{...} 完整格式做红色高亮（大小写全变体；正则统一走既有 FLAG_FORMAT_PATTERN 常量扩展）；与正则搜索高亮共存不冲突（自动标红用红色系，用户搜索用现有高亮色）。
- 菜单栏在移动端（≤520px）折叠为横向滚动菜单或分组抽屉，下拉列表仍可用。
- 只动导航与展示层，操作实现与受众分流不动。

**预期效果**：打开 CTF 工具箱，一条菜单栏在顶部，点"字符1"下拉出操作列表点【凯撒解密】立即出结果——和随波逐流同样的操作手感；任何输出里 flag 字样一眼可见（红色）。

**验收**：四门禁全绿；浏览器实测：菜单栏点击任一操作即执行（无需再点执行按钮）；输入含 `flag{test}` 与 `FLAG{UP}` 的输出全部标红；正则搜索与自动标红不互相覆盖；390px 移动端菜单可操作；console 零报错。

## 批次 M4：随波逐流操作大扩充（对齐菜单清单）

**问题**：用户要求"随波逐流有的我们也要有"。对照其全菜单截图逐项盘点，我们有约 60 个映射类/工具类操作缺口（重型文件/隐写/在线类除外，已归 v2.0.3+ 路线）。

**需求**：补齐下列操作（全部进 CTF 域受众，实现为字表映射/纯计算，零联网；算法可参考 CyberChef（Apache-2.0）、dcode.fr、CTF-Wiki 及对应开源实现如 SheepChef Abracadabra（熊曰）等 GitHub 项目）：

- **Base/Rot 组**：base92、base100（emoji）、base85(b)/Z85、base62-ASCII 变体、base64 多行解码、大小写错乱 base64 解码、base64 隐写（PE 相关可后置）、base64 转 hex、Base 自定义表(key)、Base16-32-64-91 混合多重解码、Rot18、Rot Special
- **字符类**：猪圈密码（pigpen，含变体图形对照表）、云影密码（0/1/2/4/8）、pizzini、Cisco Type7、decabit 脉冲码、Cetacean 鲸目密码、键盘 keyCode、九宫格 handycode、汉码 chinesecode、反斜杠 Backslash、斜杠管道 Slash and Pipe、汤姆码 Tomtom、表盘码 Clock、金甲虫 GoldBug、肯尼 Kenny、深渊天使 Abaddon、Dvorak 键盘、五针电报 FiveNeedleTelegraph、Hodor、鸭语 Duckspeak、NumberPadLines、Quadoo、Burrows-Wheeler Transform
- **中文类**：社会主义核心价值观编码、汉字笔画码、阴阳怪气编码、八卦符、中文电码（标准电码本）、想曰、玛卡巴卡、音音译者、兽音译者、元素周期表编码、火星文（映射层）、盲文 Braille（ UNICODE 点字表）、音符密码、花朵密码、字母密码、箭头密码、汉字密码、国际音标密码、Whitespace、Deadfish、Spoon BrainFuck、曼彻斯特 Manchester、emoji-encoder
- **带key/多key 类**：一次一密 OTP、乘法密码、FractionatedMorse 分组摩斯、Fenham 费娜姆、滚动密钥 running key、Bazeries、kamasutra、M-209、RC2、RC6
- **进制/工具类**：IEEE754 浮点互转、二进制补码/反码、进制字符串异或(key) 系列（2/8/10/16）、位分割工具（字符串两/三/四/七位分割）、海明码校验、QWE=ABC 键盘对应、GCD、素数分解（试除+Pollard rho 小规模）、斐波那契数列解密、pickle 反序列化（受限安全解析，只解基础类型）、ASCII 控制字符解码、区位码↔汉字

**方向**：
- 每个操作走既有注册三件套（OperationId + operations 元数据 + transform 实现），命名/摘要双语；映射表型操作把表数据放 `src/utils/codec/` 独立模块（参照 alphabets.ts 模式），超大表可按操作拆文件。
- 智能识别层接入高特征检测（核心价值观句子、八卦符、音符、箭头、盲文 Unicode 区、火花天书类前缀等），能自动识别的接进去。
- 带key 操作接全局密钥栏约定；M-209/RC2/RC6 算法参考公开规范实现，实现不了完整机的（M-209）可先支持主流参数档。
- 确实需要在线服务或重型解析的（随波逐流的"在线解密"菜单、stego WASM 族、pcap USB 流量提取）**不做**——已在 v2.0.3/v2.0.4 路线，本批次明确排除。
- 守恒校验数字、verify:codec 回归块随新增操作同步扩展。

**预期效果**：随波逐流字符1-4/Base/Rot/带key/进制菜单里的操作，除在线与重型隐写外，在我们的菜单栏里都有对应项且可用；智能识别对新增字表类密文能自动认出大半。

**验收**：四门禁全绿；每个新操作有 round-trip 回归（自造样本编码→解码一致，权威向量对拍不少于新增操作数的 1/3）；智能识别新增检测用样本实测命中；受众守恒校验更新后通过；菜单栏（M3）中全部新操作可达。
