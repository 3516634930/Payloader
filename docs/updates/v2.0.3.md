# Payloader v2.0.3 更新计划：EXP 源码安全库

## 目标

让 EXP 可以附带源码：管理员安全地上传源码，用户能预览和下载，且整个链路确定性、可审计。

## 需求背景

EXP 光有描述不够，使用者需要拿到源码本身。但源码上传是高危功能：路径穿越、伪装成文本的二进制、归档炸弹、跨平台路径不一致，任何一个处理不好都是安全事故。本版要建一套"默认不信任任何文件"的源码库。

## 新增/变更功能

- 管理员为 EXP 分批上传源码/纯文本文件，保留规范相对目录结构。
- 双层安全：管理员可配的扩展名白名单 + 不可关闭的系统硬拒绝（归档、二进制、字节码、路径穿越、伪装魔数、设备文件、软链接等）。
- 规范路径统一：`/` 分隔、Unicode NFC、拒绝保留名和大小写冲突，Windows/Linux/macOS 得到完全相同的路径集合与 Hash。
- 容量与配额保护：单文件上限（默认 2 MiB 可调）、每会话文件数与总字节上限、每账号并发会话数、磁盘余量不足自动拒收。
- 确定性产物：同一源码树永远生成字节一致的 ZIP + Manifest + SHA-256，跨平台可重建验证。
- 匿名预览只显示转义后的纯文本；下载由应用层校验激活状态后流式返回，绝不执行源码、不渲染富文本、不暴露直链。

## 预期效果

- 用户可以放心预览和下载 EXP 源码，拿到的文件 Hash 与平台公布的一致。
- 上传环节杜绝路径穿越、二进制伪装和资源耗尽攻击；同一棵源码树在任何平台上验证结果相同。
- 源码与 EXP 版本绑定：激活哪个版本就提供哪个版本的源码，未激活状态不可下载。
