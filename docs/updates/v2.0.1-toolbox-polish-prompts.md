## 批次 M2：动作化操作 + 常驻密钥栏 + 输出导航

**问题**：对比随波逐流实机界面，当前工作台交互密度低：执行一个操作需要"选分类 → 下拉选操作 → 点执行"三步，无全局密钥栏，输出区没有搜索与多候选导航，长输出找 flag 靠肉眼滚。

**需求**：把 CTF 两个工作台（密码编码域 CodecWorkbench、杂项/流量域的文本工作区）的交互对齐随波逐流密度：操作动作化、密钥常驻、输出可搜可导航。不改变现有操作实现与受众分流。

**方向**：
- **操作动作化**：分类侧栏点击分类后，操作列表从"下拉框"升级为可点击的动作列表/网格（每个操作一个按钮，带编码/解码标记，参考随波逐流"【xx解密】"的标记法）；点击按钮立即对当前输入执行（encode 用编码按钮、decode 用解码按钮，各只点一次）。保留下拉框作为紧凑模式备选可以，但默认动作化。
- **常驻密钥栏**：工作台工具栏增加全局密钥输入框（等价随波逐流的"密钥key/str/url"栏），带 key 参数的操作自动读它，用户可覆盖为操作私有值；多步链式处理时 key 不用反复填。参数型操作（位移数、栏数等短参数）也走这个栏的约定格式或就近小输入框。
- **输出区增强**：正则/明文搜索框（高亮命中）；flag 格式命中在输出内高亮并可 ↑结果↓ 导航跳转；字数统计（输入/输出字符数与字节数）；"输出回灌输入"一键按钮（链式手动 recipe）。
- **多候选导航**：智能解码多候选场景在输出区提供候选间跳转（↑结果↓），不止折叠列表。
- **操作补齐**（字表映射类，全部进 CTF 域 + 智能识别检测）：云影密码（0/1/2/4/8 组合编码）、pizzini、Cisco Type7 解密、decabit 脉冲码、Cetacean 鲸目密码、Albam、Carbonaro。
- 交互只动展示层与状态管理，引擎/操作实现不动；移动端动作列表退化为纵向按钮组，密钥栏保持可达。

**预期效果**：处理一道多层题的体感 = 随波逐流：粘贴 → 点"智能解码"或连点动作按钮串链 → 输出区正则搜 flag 直接命中；密钥只填一次；全程手不离键盘主区，无翻页面感。

**验收**：四门禁全绿 + 零联网；浏览器实测：一段双层编码（如 Base64 包 ROT13）从粘贴到出 flag 的点击数 ≤4；常驻密钥栏在 Vigenère→AES 两步连用时第二次无需重填；正则 `flag\{.*?\}` 搜索高亮与候选导航可用；移动端 390px 动作列表与密钥栏不溢出；console 零报错。
