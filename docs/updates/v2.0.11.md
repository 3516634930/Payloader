# Payloader v2.0.11 更新计划：复现统计与贡献者主页

## 目标

建立 EXP 复现反馈闭环：用户投票"我复现成功/失败"、审核员维护人工复现标记、贡献者获得公开主页。

## 需求背景

EXP 目录里几十个 EXP 哪个真的好用，现在只能靠用户自己挨个试。大众复现投票是最直接的质量信号，但要防止刷票和误导：投票只能做辅助排序，不能操纵内容生死。同时社区贡献者需要一个展示自己成果的地方。

## 新增/变更功能

- 用户复现投票：登录用户对当前公开的 EXP 版本投"成功复现/未成功复现"，一人一票可改；新版本独立重新计票。
- 防刷与克制：匿名只见聚合结果，不公开逐票明细；样本太少（<5）不参与排序；用统计下界（Wilson 95%）计算分数，且只能在不影响检索相关度的前提下打破同分平局，绝不改变内容的审核/发布/下架状态。
- 人工复现标记：审核员/管理员可把 EXP 标记为"已人工复现"，作为比大众投票更强的信号，新版本重置。
- 公开贡献者主页：展示公开昵称与其仍在公开状态的所有 Payload、工具、EXP 贡献；内容下架/隐藏即从主页消失；不暴露未发布投稿、审核记录、邮箱或内部 ID。

## 预期效果

- 用户挑 EXP 时多了一个可信的"大众实测"参考，少踩坑。
- 刷票无法把坏内容顶上去：投票影响被严格限制在平局打破级别。
- 贡献者有了荣誉主页，社区激励闭环成形。
