# Payloader v2.0.14 更新计划：匿名只读 MCP 服务

## 目标

在 `/mcp` 提供匿名、只读的 MCP（Model Context Protocol）接口，让 Claude Code、Codex 等 AI 编码工具能直接检索 Payloader 知识库。

## 需求背景

安全从业者的工作流正在 AI 化：写报告、做渗透时希望 AI 能直接查 Payload、工具和 EXP，而不是人工复制粘贴。MCP 是 AI 工具接外部数据源的标准协议。本版把 Payloader 变成 AI 可用的知识源——只读、匿名、安全可控。

## 新增/变更功能

- 单一远程 MCP 服务：同域名 `/mcp` 路径，匿名只读，管理员可全局开关。
- 固定四个工具，覆盖"搜索 → 详情 → 取源码"工作流：
  - `catalog.search`：轻量搜索，返回摘要、匹配证据和稳定 ID；
  - `catalog.get_many`：按 ID 批量取完整详情；
  - `exploit.get_source`：按清单内路径和行范围读取 EXP 源码片段；
  - `exploit.get_download_url`：获取 EXP 源码下载地址。
- 检索质量：先做稳定 ID、产品别名、CVE、版本范围的确定性匹配，再做全文/模糊补充；明确区分"精确命中"和"模糊命中"，并返回证据与缺失条件。
- 语言策略：相关度相同时优先中文，无中文回退英文，绝不机器翻译或伪造语言。
- 数据边界：只暴露当前激活的公开内容，隐藏/下架内容一律"不存在"；无任何写入、投稿、审核能力。
- 质量基准：建立 500+ 案例的检索评测集（含 30% 负样本和封存的测试盲集），精确率/召回率达标后才上线。

## 预期效果

- AI 编码工具即插即用地检索 Payloader：搜索、比对、取源码一气呵成，结果带证据不瞎编。
- 检索质量有基准测试背书，模糊命中不会被包装成确定结论。
- 匿名可用的同时边界清晰：外部 AI 只能看公开内容，碰不到管理面和未公开数据。
- MCP Schema 进入共享契约清单：部署版（Payloader-Enterprise）以同一 Schema 跟进实现，两版对 AI 客户端完全无感。
