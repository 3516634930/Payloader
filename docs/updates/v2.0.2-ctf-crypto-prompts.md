# v2.0.2 批次提示词：密码攻击纵深（CTF 弧线阶段 1）

> 前置：v2.0.1 批次 A-M 已完成（七域框架）。路线图见 `docs/updates/ctf-capability-roadmap.md`，调研依据见 `docs/research/ctf-tools-landscape-2026-09.md`。
> 执行顺序：N 最先（决策树+基础设施）→ O（数学工作台，可与 N 后半并行）→ P（自动分析+收尾）。
> 门禁与红线同前：四门禁全绿；零 eval/new Function；**零联网（解题链路不得发起任何网络请求，资产全部本地打包，指导页只放用户手动点的外链）**；计算限量（迭代上限/超时/BigInt 位数上限防卡死）；受众新增操作全进 CTF 域，守恒校验数字同步。

## 批次 N：RSA 攻击决策树 + 密码基础设施

**问题**：RSA 题是密码题最大题库，但工具箱只有零散操作——用户要自己判断"这题该用哪个攻击"，缺一个 RsaCtfTool 式的自动决策入口。

**需求**：密码与编码域新增「RSA 决策树」向导：输入公钥（PEM/十六进制 n,e）和密文，自动依次尝试多种攻击，命中即解出并展示完整推理链；同时补齐 p,q→PEM、公钥全参数解析、本地素数资产库三件基础设施。

**方向**：
- 决策树（BigInt 纯 JS）：低指数直接开方 → 多密钥 gcd/Batch GCD → Fermat（p,q 接近）→ Pollard p-1（光滑）→ Pollard rho（小因子）→ Wiener（连分数，d 大）→ 共模（同 n 异 e）→ Håstad 广播 → 部分泄露恢复（已知 p 高位/低位、已知 d 部分）→ 形素数检测（Mersenne/斐波那契/primorial）→ ROCA 检测 → 本地历史素数表比对。每步限时/限量，全部失败时输出"已尝试 X 种 + 下一步建议"。
- **本地素数资产库**：内置历史 CTF 比赛素数表（参考 RsaCtfTool 的 pastctfprimes/noveltyprimes 思路，离线 JSON 打包进应用），决策树比对 n 是否为已知历史素数乘积。硬约束：**全程零联网**——不接 factordb 等任何在线服务；全部失败时给出手动核查的指导页（含用户自己打开的 factordb 链接），工具本身不出网。
- 推理链展示是核心体验：每步显示"尝试了什么攻击、依据什么条件、为什么失败/成功"，像解题向导不像黑盒。
- rsatool 基础设施：已知 p,q（含补全）→ 生成 PEM 私钥（BigInt + 手写 ASN.1 DER 编码）；公钥解析 dump 全参数（n/e/d/dp/dq/qinv）。
- 安全红线：所有分解尝试有迭代上限（如 rho ≤ 2^22 步、p-1 素数幂 ≤ 2^16），超限明确提示而不是卡死页面。

**预期效果**：粘贴一道"e 很小"或"共模"或"p,q 接近"风格的 RSA 题，决策树几秒内自动命中并给出明文与完整推理过程；全不命中时诚实告知并给下一步指导。

**验收**：四门禁全绿；自建 15 道 RSA 用例（覆盖低指数/共模/Fermat/Wiener/p-1/gcd/部分泄露各 ≥2 道）自动解出 ≥13 道；推理链每步可读；超限时可中断不卡死。

## 批次 O：格/椭圆曲线/PRNG 数学工作台

**问题**：格密码（HNP/背包/小维 NTRU）近年占比持续上升，椭圆曲线 nonce 恢复与 PRNG 预测是高频考点，浏览器端全部空白。

**需求**：三个数学工作台：JS-LLL 格求解、ECC/DSA nonce 恢复、PRNG 状态恢复与预测。

**方向**：
- JS-LLL：BigInt 有理数 LLL 约化（≤60 维）+ Babai 最近平面；预置模板——HNP、低密度背包、截断 nonce、共模小根；模板只要求用户填参数，构造格的过程可视化（显示基矩阵）。
- ECC/DSA：椭圆曲线点运算（P-256/P-384/secp256k1，可自引用 WebCrypto 或 noble-curves 思路自实现）；k 重用恢复私钥（两签名 gcd 类代数）；同 nonce 不同消息、连续分数攻击。
- PRNG：MT19937 untemper（624 输出→恢复状态→预测后续/回溯）、时间戳种子爆破（给定时间窗穷举）、glibc rand/Java java.util.Random 状态恢复。
- 全部进密码与编码域「现代密码攻击」分组（或按需新增"数学工作台"分组）；智能识别层无需接入。

**预期效果**：一道 HNP 题：填入参数→LLL 约化→出解；两段 ECDSA 签名贴入→直接恢复私钥；624 个 MT19937 输出贴入→预测下一个。

**验收**：四门禁全绿；LLL 用已知 HNP/背包小参数实例验证正确（对拍 Sage/已知答案）；ECDSA k 重用对拍已知向量；MT19937 用 Python random 生成 624 输出实测预测全对；60 维内耗时 <5 秒（超维度明确拒绝）。

## 批次 P：自动密文分析面板 + 哈希指导链 + 收尾

**问题**：拿到一堆密文/哈希/Token 时，用户要自己逐个试工具；FeatherDuster 已证明"自动分类+批量分析"的价值，工具箱缺这个总览面板。

**需求**：密码与编码域新增「自动分析」总览：粘贴任意内容（或批量多段），自动分类并给出分析结论与下一步建议；哈希识别接 hashcat 指导链；本阶段收尾走查。

**方向**：
- 自动分析面板（FeatherDuster 功能清单）：编码层剥离检测（base64/hex/zlib/URL 套层）、分组 vs 流密码判定（分组长度对齐）、ECB 检测（重合块）、低熵/高熵标注、OpenSSL Salted__ 格式识别、RSA 模数重用检测、many-time pad 检测（多段异或）、长度扩展漏洞特征标记；每类结论附"用哪个工具继续"的直达链接（跳对应操作）。
- 哈希识别→指导链：hashid 式签名表（内置 200+ 格式）识别后，展示"hashcat -m 编号 + 现成命令 + john 等价命令"（L3 指导模式，不真破解；小字典的 MD5/SHA1/NTLM Worker 字典攻击可选做）。
- 哈希长度扩展攻击计算器：选算法（MD5/SHA1/SHA256）、输入已知 sig/原文/追加内容，出伪造 sig（核心=中间状态续算）。
- 收尾走查：RSA 决策树/数学工作台/自动分析三旅程实景 + 防呆（超大 BigInt 粘贴、非法 PEM、全垃圾输入诚实报错）+ 移动端 + 亮暗主题。

**预期效果**：把一段不明密文丢进自动分析，10 秒内得到"这是 OpenSSL AES-CBC，密钥派生 MD5，用这个工具继续"式的结论；哈希粘贴出格式识别与现成破解命令。

**验收**：四门禁全绿 + 走查证据 + P2 记账；自动分析对 10 类特征样本全部给出正确分类与正确跳转；长度扩展对拍 hash_extender 已知向量。

## v2.0.2 总验收

- RSA 决策树 15 用例 ≥13 解出；LLL/ECDSA/MT19937 对拍全对；自动分析 10 类特征全对
- 全程 BigInt 限量红线：任何计算超限可中断、有提示、不卡 UI
- **零联网验证**：浏览器网络面板审查整个解题流程零请求；代码层 grep 无 fetch/XHR/WebSocket 新增
- 密码域操作数增长与受众守恒校验同步更新；渗透视图零污染
