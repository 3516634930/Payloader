# Payloader v2.0.7 更新计划：注册与账号恢复

## 目标

开放受控的用户注册：多种注册策略、邮箱验证、邀请制与密码自助恢复，配套可靠的邮件发送能力。

## 需求背景

v2.0.7 建好了用户体系，但账号还只能由管理员手动创建。社区化运营需要用户能自己注册、自己找回密码，同时平台要能控制"什么人能进来"。

## 新增/变更功能

- 四种注册策略，管理员可切换：关闭（默认）、开放注册、注册需审批、仅邀请制。
- 邮件能力：SMTP/TLS 配置加密保存，后台带测试邮件功能；邮件走异步队列发送，失败可重试、可观察、可恢复。
- 邮箱验证：开放注册先验证邮箱；审批模式验证后进入待批准队列；邀请严格绑定指定邮箱。
- 密码自助恢复：普通用户可用已验证邮箱重置；审核员仍由管理员发临时密码；唯一管理员只允许离线恢复。
- 安全细节：管理员改用户邮箱后立即撤销会话并要求重新验证；邮件链接只来自可信配置，禁止从请求头推导；秘密（令牌、密码、SMTP 密钥）永不进日志。
- 范围克制：只发注册验证、邀请、账号恢复三类邮件，不发业务通知。

## 预期效果

- 平台可以按运营阶段自由切换获客策略：从完全封闭到邀请制再到开放注册。
- 用户忘记密码能自助找回，管理员不用当"人肉密码重置机"。
- 邮件发送可靠且不阻塞用户操作，发信配置泄露不影响系统安全。
