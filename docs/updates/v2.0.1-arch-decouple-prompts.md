## 全局红线（每批必守）

1. **门禁序列**（每批完成后全跑）：`npm run verify:codec`（133 项基线）→ `npm test`（236 项基线）→ `npm run typecheck` → `npm run lint` → `npx vite build`。任何一项红即停下修复，不许带红提交。
2. **纯移动优先**：机械迁移（style/纯函数/模块拆分）内容零改动，文件头注明"自 xxx 机械迁移"；只有拆分线明确的逻辑收敛才允许改行为，且必须列出行为差异点。
3. **源码文本断言同步清单**（这些测试用正则匹配源码，重构动到即碎）：tests/frontend-contract.test.mjs（38 处，重点 L12 懒加载精确串、L564 pendingFile 表达式、L431-441 admin 段）、tests/production-config.test.mjs（admin-server 源码断言 + Dockerfile CMD `admin-server.mjs` **文件名不可改**）、tests/project-attribution.test.mjs、scripts/verify-project-attribution.mjs（拆出新文件须加入 runtimeFiles 扫描名单）、verify-encoding-tools.mjs L2790-2807。改了结构必须同步改断言，同步改动要在 commit message 里逐条列出。
4. **禁止推远端**：只本地 commit。每批一个 commit，message 格式 `refactor(scope): 内容摘要`。
5. **不可破坏语义**（server 线）：data-store.mjs 顶层读 `PAYLOADER_DATA_DIR` 的单点冻结语义（测试 cache-bust 依赖）；data-store 的 `routeResource` 宽松版必须继续导出（frontend-contract L34 文本断言）；写路径必须继续走 `enqueueMutation` 串行队列。
6. **codec 语义不变**：`Operation.run` 同步签名不改为异步；verify:codec 的 133 项与注水链路（hydrateCodecHeavyData → ngramTableData 动态 chunk）行为不回归。
7. 前端改动遵守既有 UI DNA：Mantine 9、CSS 变量、中英双语、手机端适配；style 迁移零插值机械走。
